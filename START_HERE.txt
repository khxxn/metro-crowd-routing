혼잡도 길찾기 — "5분 더 걸려도 덜 붐비는 길은?"
=================================================

서울·수도권 지하철에서 가장 빠른 길과 덜 붐비는 길을 알고리즘별로 비교하는 프로그램입니다.

1. 준비물
   - Python 3.10 이상 (https://www.python.org/downloads/)
   - 그 외 설치할 것은 없습니다. 화면(UI)은 파이썬 기본 기능만 씁니다.

2. 실행
   - Windows : run.bat 을 더블클릭
   - 맥·리눅스 : 터미널에서  bash run.sh
   - 직접 실행 : python app.py --open
   브라우저가 열리지 않으면 터미널에 나온 주소(보통 http://127.0.0.1:8765)를 브라우저에 붙여넣으세요.
   끝내려면 터미널 창을 닫거나 Ctrl+C 를 누르세요.

3. 화면 사용법
   - "경로 비교" 탭: ① 출발·도착역을 호선별로 고르고 ② 요일·시각·조건을 정하고 ③ 비교할 알고리즘을 고른 뒤 "경로 찾기".
     아래 예시 버튼을 누르면 바로 결과를 볼 수 있습니다.
   - "실험 결과" 탭: 무작위 출발·도착 쌍으로 알고리즘을 비교한 실험 결과(표와 그림)입니다.
   - 각 화면 요소 밑의 파란 설명 상자에 "사용한 것 / 만든 방식"이 적혀 있습니다.

4. 터미널에서 쓰기
   python route.py 선릉 수서 weekday 08:30 --algo astar
   (--algo: dijkstra | astar | larac | ga | ref,  --mode A|B,  --base 로 서울 1~9호선만 사용)

5. 꼭 알아둘 점
   - 서울 1~9호선은 팀 데이터(혼잡도·환승 실측)입니다. 그 밖의 수도권 16개 노선은 추정값입니다
     (혼잡도 0, 첫차·막차 05:30~24:00, 환승은 subway-etl 값). 그래서 점수가 실제 시간과 같게 나오고,
     점수를 줄이는 알고리즘이 그 노선을 유리하게 고릅니다. 새 노선이 들어간 결과에는 "추정" 표시가 붙습니다.
   - data/ 폴더에는 팀 공유 데이터가 들어 있습니다. 팀 밖으로 공유하기 전에 확인하세요.
   - 유전 알고리즘은 팀원 구현이 algorithms/genetic.py 에 연결되기 전까지 "구현 대기"로 표시됩니다.

6. 더 보기
   - README.md : 알고리즘 설명, 가정, 실험 재현 방법
   - CLAUDE.md : 팀 공통 비용 식과 데이터 규칙
   - 테스트·실험을 돌리려면:  pip install -r requirements.txt  후  pytest  /  python -m experiments.run
